📦 COMMENT PARTAGER
-------------------

Option 1 : ZIP
--------------
1. Créer un dossier "LinkedIn-Scraper-V2"
2. Copier tous les fichiers OBLIGATOIRES dedans
3. Créer un ZIP
4. Envoyer par email, AirDrop, ou clé USB

Option 2 : GitHub (si vous êtes à l'aise)
-----------------------------------------
1. Créer un repo GitHub PRIVÉ
2. Ajouter tous les fichiers (sauf ceux à ne pas partager)
3. Partager l'accès à la personne

Option 3 : AirDrop (Mac uniquement)
------------------------------------
1. Sélectionner tous les fichiers obligatoires
2. Clic droit > Partager > AirDrop
3. Envoyer au Mac de la personne

⚠️ IMPORTANT
-------------
- Ne partagez JAMAIS votre fichier .secure_cookie
- Ne partagez JAMAIS votre base de données linkedin_scraper.db
- Ces fichiers contiennent vos données personnelles LinkedIn
